## Tried

- `ssh -R` from decent-spider to receiver 0.2.0 on agent-jail: chunks sent 250 ms apart arrived 250 ms
  apart. `sftp -b` put a mode-600 token and ran a second time without harm.
- cpal + symphonia + hound prototype on agent-jail (PipeWire through PulseAudio): with the default buffer,
  playback started 1.9 s late and lost its last 2 s (user heard it cut at "any"); a recording lost 2 s.
  With a fixed ~20 ms buffer both ways and a wait for the reported device latency (39 ms) before closing:
  first sound ~0.1 s, whole sentence for PCM, MP3 and open-size WAV, clean silence on a 3 s stall, a
  5.96 s recording of 6 s; user confirmed each by ear. The USB mic delivers i24, which must be accepted.
- Remote server OS: not assumed Unix; the plan keeps TCP + token over `ssh -R` and pairs with `sftp -b`.
- The user dropped the second history format (WAV + MP3 via ffmpeg); it was for testing only.
